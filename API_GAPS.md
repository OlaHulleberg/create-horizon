# API gaps

What the port is missing as of 2026-11-21, at Sunrise Nightly `94256510f7` in `create/sunrise-mod.toml`.
These rows include gaps in the SDK and APIs the port has not adopted yet. Better APIs wait until after parity. Since `94256510f7`, `Compound` keys iterate in Java's HashMap order (`compound-traversal`): output that relies on sorted keys sorts them itself.
Links point to the Create 6.0.11 source (`b62e837`) that uses the missing feature.

## Vanilla behaviour with no NeoForge extension (planned `[[native.mixin]]`)

- Keep the cardboard disguise crouched without resizing the player: `Player.canPlayerFitWithinBlocksAndEntitiesWhen` (check `entity_size` first).
- Let diving boots change lava velocity after collision and before drag: `LivingEntity.travelInLava`.
- Choose the mounted player's item-touch area without resizing either body: `Player.aiStep`.
- Use a mounted mob's own box for melee reach: `Mob.getAttackBoundingBox`.
- Allow eligible hits on shared-vehicle riders: `Projectile.canHitEntity` (separate from Create's existing crosshair-picking change).
- Retry large water wheel placement at an offset after failure: `BlockItem.place`.
- Let ejectors and seats change motion at vertical contact before vanilla bounce: `Entity.restituteMovementAfterCollisions`.
- Let controller rails adjust cart motion during the rail step using the effective speed cap: `OldMinecartBehavior.moveAlongTrack` and `NewMinecartBehavior.moveAlongTrack`.
- Choose baked face culling for copycats and connected glass without changing fluid faces: `Block.shouldRenderFace`.
- Share mining cracks across a multiblock until the original crack clears: `ClientLevel.destroyBlockProgress`.
- Apply the skyhook rider's final pose before the body, armour and held items draw: `HumanoidModel.setupAnim` (check `humanoid_setup_anim` first).
- Treat a deployer as smoke-protected when it harvests a hive: `BeehiveBlock.useItemOn` (`CampfireBlock.isSmokeyPos`).
- Stop fluid from spreading along a water wheel's axle: `FlowingFluid.canPassThroughWall`.
- Let open pipes check fire immunity and ignite boats and projectiles: `Entity.fireImmune` and `Entity.igniteForSeconds`.
- Group inventory views over the same backing slots for stock counting: `WorldlyContainer.getSlotsForFace` and `CompoundContainer.contains`.
- Copy requested server debug info on the matching reply: `KeyboardHandler.setClipboard`, as in `KeyboardHandler.copyRecreateCommand` and `DebugQueryHandler.handleResponse`.

These parts will be built for the exact game build, and the fit check verifies that match.

# Migration ledger

The original corpus is pinned to [Delete228/create-horizon `b99cab5`](https://github.com/Delete228/create-horizon/tree/b99cab50ffdccdcc827e54d547b39c81a53efe11/tools). These tests originally used Create 6.0.10. Every executable Java reference in this PR is rebuilt from the 6.0.11 source pin in `reference.json`.

This is an inventory of 66 reference-oriented programs, not a claim that all were ported. 15 programs contribute matrices or observations here. The remaining programs are explicitly listed below; they are **not executed and not counted as passing**. Original native-only tests and reference preparation/data-generation utilities are outside this behavioural inventory.

“Matrix” means the original input matrix and observations were transferred. “Partial observations” means a narrower public-engine contract; each suite describes its projection and unavailable cases. `motion-primitives` is supplemental, not a substitute for the original moving-world tests.

Names, source hashes and exact origin revision are also in [origin-inventory.json](origin-inventory.json). Original programs are linked for the remaining work rather than copied with broken imports, private player paths or dependencies on the old mixin port.
